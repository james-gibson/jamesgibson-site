# tuner

A live data broadcaster. It carries current state to the surfaces that display it.

The problem it answers: a dashboard that shows a cached value is a dashboard about the past. tuner
supplies the live half of the picture that [adhd](/work/adhd) and [lezz.sea](/work/lezz-sea)
display.

Repository: [james-gibson/tuner](https://github.com/james-gibson/tuner).
