# lezz.sea

A macOS dashboard for the lights produced by [adhd](/work/adhd) and the live traffic coming
through the lab's MCP surfaces.

The problem it answers: state that lives in a terminal is easy to miss. lezz.sea puts the alarm
state and the current traffic on screen, where a change is visible without polling a log.

Repository: [james-gibson/lezz.sea](https://github.com/james-gibson/lezz.sea).
