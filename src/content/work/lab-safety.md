# lab-safety

Safety data sheets and lab exercises for the MCP surfaces. Unlike the other projects here, it is
a documentation corpus rather than an application: the repository is the publication, and the
README is the landing page.

The corpus separates what a control **declares** from what the code **enforces**. A page that
claims a check exists has to point at the code that performs it; otherwise it stays marked as
declared. That distinction is the argument of the whole corpus.

Repository: [james-gibson/lab-safety](https://github.com/james-gibson/lab-safety).
