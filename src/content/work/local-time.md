# local-time

A temporal universe library. It models time as epochs and keyframes and lets references cross
from one universe into another.

The problem it answers: a coordinate without its epoch is not an answer. Two systems can record
the same instant under different conventions and disagree forever about what happened. local-time
keeps the epoch attached to the value so the reference can be re-derived later.

Repository: [james-gibson/local-time](https://github.com/james-gibson/local-time).
